## Agenda de Contactos

- Aplicación web desarrollada con **React.js** para gestionar contactos de manera sencilla e intuitiva.
- Permite agregar, editar y eliminar registros, mostrando la información de forma organizada y accesible. 

**Demo:** [Agenda de Contactos](https://agenda-de-contactos-seven.vercel.app/)

### Funcionalidades

- Agregar nuevos contactos  
- Editar datos de contactos existentes  
- Eliminar contactos  
- Visualización de la lista de contactos  

### Tecnologías utilizadas

- **React.js**  
- HTML5, CSS3  
- JavaScript ES6+
- Deploy en **Vercel**
